# Currency Converter 💱

A simple and responsive Currency Converter web application built using **HTML**, **CSS**, and **JavaScript**. This app allows users to convert amounts between different world currencies in real-time using a live exchange rate API.

## Features ✨
- **Real-time Conversion:** Fetch up-to-date exchange rates using a currency API.
- **Dynamic Country Flags:** Automatically updates the country flags matching the selected currencies using FlagsAPI.
- **User-Friendly Interface:** Clean, modern, and responsive design with intuitive card layouts.
- **Default Selections:** Pre-configured with default currencies (e.g., USD to PKR) for quick use.

## Technologies Used 🛠️
- HTML5
- CSS3
- JavaScript (ES6+)
- Currency API (`fawazahmed0/currency-api`)
- FlagsAPI
